会话引用（@chat 徽章 → 链接）端到端数据流
基于 desktop/frontend/src 实际代码结构 · 三态：编辑态 → 传输态 → 展示态
① 发送端 · 输入框（Composer / RichComposerInput）
1. 敲 @ → 打开统一面板（menuMode="at"）
▼
2. 跨字段搜索（atMenuSessionMatches）
title / topic / preview / path / workspace 小写子串
▼
3. 插入原子徽章（InvocationBadge）
💬 会话A ✕ contentEditable=false，整体删除
模型：{ text, invocations:[{id, offset, session}] }
② 发送 · 折叠为文本标记
4. serializeInvocationSubmit
徽章 → 纯文本 marker：
@chat[.reasonix/s1|会话A]
文件 → @file[path|name] · 技能 → /name
▼
5. 传输/存储
消息 = 带 marker 的纯文本 + referenced-session context（提交时注入被引用会话上下文）
③ 接收端 · 按数据重建
6. tokenMatches 正则解析
@chat\[([^\]]+)\]
▼
7. parseSessionMarkerBody
path | title → 还原结构化引用
▼
8. 渲染徽章 + 点击跳转
💬 会话A 点击 → 按 path 定位/打开会话（deep link）
编辑回填 / 复制粘贴：marker ↔ 徽章往返恢复
底层模型：「纯文本 + 实体偏移」
我在整理 @chat[.reasonix/s1|会话A] 的设计方案
text 节点：「我在整理 」
实体 { type: session, offset: 5, len: 23, path, title }
text 节点：「 的设计方案」
path 是权威 ID，title 只是展示快照
传输层永远不含 HTML → 防 XSS / 防注入
原子 token 不可拆分编辑，只能整体删除
marker 语法可往返：copy/paste、编辑回填、历史恢复
纯文本可降级：通知/搜索场景显示原文也不崩
